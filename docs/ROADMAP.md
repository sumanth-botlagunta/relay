# Roadmap

These are priorities, not delivery promises. Propose a focused issue before starting a large change.

1. **Reduce installation friction:** Apple Developer ID signing and notarization, then a verified Homebrew cask and a secure update path.
2. **Broaden compatibility evidence:** macOS 15 testing on Apple Silicon, Chrome profile/private scenarios, VoiceOver, multiple displays, and managed Macs.
3. **Improve onboarding:** clearer first-run guidance and permission recovery, with fewer interruptions.
4. **Expand browser support carefully:** explicit profile/private destinations only when launch behavior can be tested reliably.
5. **Help people manage rules:** safe import/export with a privacy review, and clearer feedback about conflicting rules.
6. **Prepare localization:** accessible labels and translatable user-facing strings.

The first public release focuses on a small, local, dependable browser picker. Accounts, cloud synchronization, and tracking are not required for that purpose.
