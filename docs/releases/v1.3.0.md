# Relay 1.3.0 — first public release

Relay is a free, MIT-licensed browser picker for macOS 15 and later. Choose a browser for clicked links, route familiar sites automatically, use Chrome profiles or Incognito, and inspect cleaned URLs.

## Download

Choose `Relay-1.3.0-apple-silicon.dmg`, drag Relay to Applications, and open it. The ZIP contains the same app. Both downloads include Apple Silicon code; `SHA256SUMS.txt` lists their checksums.

**Testing build:** ad-hoc signed, not Apple Developer ID signed or notarized. If macOS blocks first launch, follow [Apple’s instructions](https://support.apple.com/guide/mac-help/mh40616/mac) only if you trust the download. Do not disable Gatekeeper. Managed Macs may not allow it.

## Included

- Browser picker with mouse and keyboard controls, exact-domain memory, and link details.
- Ordered link queues with Skip, dismiss-all, and launch-failure recovery.
- Domain/source-app rules, temporary defaults, Pause, and held-key overrides.
- Tracking cleanup, local suspicious-link warnings, and current-tab transfer.
- Public installation, privacy, security, contribution, and testing guides.
- CI checks and a reproducible Apple Silicon release workflow.
- A neutral app identifier and improved singular waiting-link accessibility text.
- Relay copies from older or development builds are excluded from browser discovery and rejected at launch, preventing Relay-to-Relay routing loops.

## Upgrading from a private build

Quit Relay, replace the app, and choose Make Default again. Check Launch at login and Automation permission; macOS identifies this public build separately. Existing JSON preferences remain in place. Do not run both builds together.

## Validation and known limits

The regression suite covers 151 expectations. Releases require tests, Apple Silicon compilation, architecture verification, and ad-hoc signature checks before publishing. Interactive behavior has been checked on Apple Silicon; full accessibility and multiple-display coverage remain open testing needs. Chrome-specific profile/private launches depend on Chrome’s command-line behavior. Relay has no automatic updater.

Report issues with synthetic example links and include macOS, Relay, and browser versions. Do not attach personal settings or browsing history.
